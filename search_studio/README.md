# `search_studio/` — Production Search & SetFit-MiniLM Router Package

Modular Python package powering the 3-stage **Entertainment Agent Search** pipeline:
1. **Stage 1 (`router_api.py`)**: **SetFit-MiniLM Contrastive Classifier** (`0.9 ms` CPU ONNX / `7.6 ms` GCP Vertex AI Endpoint) deciding whether an incoming query requires LLM intent extraction (`CALL_LLM_INTENT`) or can go directly to Vertex AI Agent Search (`DIRECT_AGENT_SEARCH`).
2. **Stage 2 (`intent_extractor.py` + `compiler.py` + `taxonomy.py`)**: **Conditional 8-Key LLM Slot Extractor & Deterministic Boost Compiler**, invoked only when `call_llm_for_intent == true`.
3. **Stage 3 (`search_service.py` + `client.py`)**: **Vertex AI Agent Search Dispatcher** with 3-ring Concentric `GEO_DISTANCE` proximity boosting, entity deduplication (`crowdingSpecs` on `entity_code`), and 0-hit sub-locality fallback.

> **Archived Experiments:** Previous multi-model router experiments (Local & Vertex vLLM Gemma 3 `1B`/`270M`, `gemini-3.5-flash-lite`) are archived in [`../archive/experiments_v1/`](../archive/experiments_v1/).

## 1. Package Module Map

| Module | Responsibility |
| :--- | :--- |
| **[`router_api.py`](./router_api.py)** | **SetFit-MiniLM Decision Classifier (`GET / POST /api/route_decision`)**<br>• [`decide_query_route_setfit_minilm()`](./router_api.py): In-process CPU ONNX inference (`setfit:minilm-l6-v2`, `0.9 ms` P50).<br>• [`decide_query_route_vertex_setfit()`](./router_api.py): Calls the dedicated GCP Vertex AI Endpoint (`vertex:setfit-minilm-l6-v2`, Endpoint `1848149303919378432` in `asia-south1`).<br>• [`handle_route_decision_request()`](./router_api.py): HTTP handler supporting `"include_reason": true|false` and `"execute_search": true`. |
| **[`setfit_minilm_router_weights.npz`](./setfit_minilm_router_weights.npz)** | Portable NumPy weights (`672.8 KB`) for the SetFit Contrastive Residual Projection Head (`384 -> 256 -> 128`), Primary Route Classifier, and 7 Multi-Label Facet Heads (`city`, `date_time`, `price`, `format`, `language`, `genre_category`, `negation`). Generated by [`../train_setfit_router.py`](../train_setfit_router.py). |
| **[`intent_extractor.py`](./intent_extractor.py)** | **Conditional 8-Key LLM Slot Extractor**<br>• [`extract_boosts_llm()`](./intent_extractor.py): Extracts compact JSON slots (`type`, `city`, `locality`, `fmt`, `langs`, `genres`, `cats`, `min_price`, `max_price`, `date`, `time_slot`, `no_genre`, `q`) when `call_llm_for_intent == true`. |
| **[`compiler.py`](./compiler.py) & [`taxonomy.py`](./taxonomy.py)** | **Deterministic Boost & Geo Compiler (~0.05 ms)**<br>• [`serialize_llm_slots_to_boost_specs()`](./compiler.py): Expands compact LLM slots into exact BigQuery/Vertex `conditionBoostSpecs` (`regions: ANY(...)`, `min_price`, `formats`, `languages`, `show_dates`, `time_slots`) and `location:GEO_DISTANCE(...)` filters. |
| **[`search_service.py`](./search_service.py)** | **Search Execution & Concentric Proximity Boosting**<br>• [`run_live_search()`](./search_service.py): Runs the default `"auto_route"` pipeline (**SetFit Classifier $\rightarrow$ Conditional LLM $\rightarrow$ Vertex AI Agent Search**), stacks 3 concentric `GEO_DISTANCE` rings (`<=3 km`, `<=10 km`, `<=25 km`), and computes Haversine distances. |
| **[`client.py`](./client.py)** | **HTTP & Auth Client (`ADC` + `EcpClient`)**<br>• Uses Google Cloud Application Default Credentials (`google.auth`) with persistent HTTP keep-alive connection pooling on Cloud Run / Vertex AI, falling back to local `ecp_http_proxy` mTLS on corp machines. |
| **[`prompts.py`](./prompts.py)** | **LLM System Instructions**<br>• [`GEMINI_INTENT_SYSTEM_INSTRUCTION`](./prompts.py), [`build_gemma_chat_messages()`](./prompts.py), and [`build_explain_hit_prompt()`](./prompts.py). |
| **[`server.py`](./server.py) & [`ui.html`](./ui.html)** | **FastAPI Local UI & Proxy Server (`http://127.0.0.1:8080`)**<br>• Serves [`ui.html`](./ui.html) and pre-warms the SetFit-MiniLM ONNX runtime at startup. |
